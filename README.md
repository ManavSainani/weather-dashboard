# Weather Dashboard 

A Python desktop application that retrieves and displays real-time weather information for cities using the OpenWeatherMap API.

## Overview

Weather Dashboard provides a simple graphical interface where users can search for a city and view current weather information.

## Features

- Search weather by city
- Temperature in Celsius and Fahrenheit
- Weather information
- Real-time API data
- Desktop GUI

## Tech Stack

- Python
- PyQt5
- OpenWeatherMap API
